# Start a story

Follow [`docs/playbooks/start-story.md`](../../../docs/playbooks/start-story.md) step by step.

- The story id comes from the invocation arguments: $ARGUMENTS. If no id was given, ask the owner which story to start.
- Talk to the owner in Peninsular Spanish. Write every repository artefact in technical English.
